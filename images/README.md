# Media storage moved to Google Drive

Praise & Peace approved JPG/PNG image files are now stored in **Google Drive**, not this repository.

The approved November 19, 2026 release `PP-2026-11-19` references a Drive image in `posts/PP-2026-11-19.json`.

**Do not upload any image files to this directory.** GitHub stores release manifests, captions, verification scripts, and results only.

Important: Google Drive's standard public preview URL is not a guaranteed direct image URL for Meta's Instagram content publishing API. The publisher will not run until an anonymously downloadable, direct JPEG delivery URL has passed validation and been added to the approved manifest. The Google Drive image remains the source-of-truth asset.
